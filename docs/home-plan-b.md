# 홈 B안 (2026-11-20 시안)

> **2026-11-20 정리**: 사이드바 정리 · 에디터 상단 바(아이콘 + 제목, 데스크톱 ‹ 숨김) · 딸깍 AI 정리는 **지금 홈에도 적용**했다(사용자 "메인 화면 빼고 에디터 · 딸깍 AI · 사이드바는 지금 홈에도"). 이제 두 시안은 **홈 메인 화면만** 다르다. 아래 "B안 사이드바" · "B안 에디터 상단 바" 절은 두 시안 공통 내용으로 읽으면 된다.

지금 홈은 그대로 두고, 홈 오른쪽 아래 **[홈 시안: 지금 홈 | B안]** 스위치로 비교한다. 고른 값은 이 브라우저에 기억(`localStorage` `ddalkkak.homeVariant`).

## 왜

- 딸깍넷이 ChatGPT · Claude와 다른 점(사용자 정리): **정확한 양식** + **원하는 느낌의 템플릿** + **직접 고치는 에디터**(한글 · 피그마 · 포토샵형).
- 지금 홈의 문제: 핵심 동선인 편집기 줄이 작고 아래에 있음, 이어서 하기(최근 파일)가 없음, 시작하는 길이 요청 작성 도우미 · 검색창 · 편집기 줄로 흩어짐, 템플릿을 편집기별로 못 고름.
- 참고: Microsoft 365 · Google 문서(맨 위 "새로 만들기" 줄 → 최근 파일), Canva · 미리캔버스(종류 아이콘 줄 → 최근 디자인 → 템플릿).

## 구성 (위에서부터)

1. **딸깍 한 번이면, 양식부터 내용까지**(딸깍만 파랑) + 서브 "만들 문서를 적으면 맞는 양식을 찾아 AI가 채워 줘요. 고칠 곳은 편집기에서 바로 고치면 돼요."(2026-11-20 다시: 지금 홈 "딸깍 한 번이면, 작업은 더 빠르게" 말투를 잇는다. 예전 "양식 그대로, AI가 채우고, 직접 고쳐요") + 입력창 "무엇을 만들까요?". 예시 칩(행사 개최 공문 · 견적서 · 회사 소개 발표 · 카드뉴스 · 주간 업무 보고)과 "막막하면 요청 작성 도우미".
   - 적으면 답을 쓰지 않고 세 묶음으로 안내: ① **정확한 양식**(한글 · 워드 · 엑셀 템플릿) ② **디자인 템플릿**(PPT · 이미지 · 영상) ③ **빈 화면에서 시작**("엑셀에서 AI로 ‘재고 관리’ 쓰기", 적은 말로 편집기를 고름).
2. **새로 만들기**: 편집기 8칸(그림 + 이름 + 무엇을 만들 때 누르는지 한 줄). 누르면 빈 파일. 그래서 홈에는 따로 "새로 만들기" 버튼이 없다.
3. **최근 작업**: 편집기 파일 카드 6개(이어서 하기). 파일이 없으면 숨김.
~~4. **템플릿으로 시작하기**~~: 2026-11-20 사용자 요청으로 뺐다. 템플릿은 위 "인기 템플릿으로 시작하기" 캐러셀 · 전체 보기 · 각 편집기 템플릿 패널에서 고른다.

- 템플릿 [AI로 채우기] → 그 편집기가 템플릿을 넣은 채로 열리고 "○○ 내용 채우기" 카드가 펼쳐진다. [그대로 열기] → 템플릿만 넣고 연다.
- 빈 화면에서 시작 → 그 편집기가 열리고 딸깍 AI 입력창에 적은 말이 들어가 있다.
- 홈 첫 방문 온보딩은 지금 홈에서만.

## 홈 비주얼 (2026-11-20 보강)
- 사용자 "지금 홈처럼 시각적으로 확 사로잡는 형태를 더 좋아하심". → 새로 만들기를 검색창 바로 아래 **큰 그림 아이콘 줄**(80px, 이름 16 + 한 줄 설명)로, 그 아래에 지금 홈의 **큰 이미지 캐러셀 "인기 템플릿으로 시작하기"**를 그대로. 편집기별 템플릿은 그림(cover)이 있는 것을 앞에, 카드 그림은 꽉 차게.
- 순서: 문구 + 입력창 → 새로 만들기(큰 아이콘) → 인기 템플릿 캐러셀 → 최근 작업 → 템플릿(편집기 칩).

## 사이드바 (두 시안 공통, 처음엔 B안에만 넣었다)
- 메뉴: 홈 · 내 작업 · **＋ 새로 만들기**(누르면 편집기 8개 고르는 창). **즐겨찾기 메뉴는 없음**. 새로 만들기는 다른 메뉴와 같은 모양 · 같은 색이고, 가는 곳(홈 · 내 작업) 다음에 둔다(사용자 "홈이 맨 위가 편할 듯", Notion · Figma 방식).
- 목록: **📌 고정**(최대 5, 줄에 마우스를 올리면 나오는 고정 버튼, 이 브라우저에 기억)
- 고정 정리(2026-11-20): 사이드바는 예전 그대로(파일 · 대화 모두 고정, 고정한 줄은 고정 풀기 버튼이 늘 보임). 내 작업에서는 고정해도 순서가 바뀌지 않고(정렬은 고른 기준 그대로) 이름 옆 📌만, 고정 버튼은 파일 줄에 마우스를 올렸을 때만
- 최근 하나로(2026-11-20, 사용자 "최근으로 하나로 합치자"): 오늘 · 이번 주 · 이전 묶음을 없애고 "최근" 한 묶음(10개). 묶음 이름 "고정" · "최근"은 같은 자리(줄 아이콘과 같은 왼쪽 선), "고정" 앞 📌 아이콘은 뺐다
- 줄 오른쪽 = [⋯][📌], 둘 다 마우스를 올렸을 때만(고정한 줄도, 사용자 "고정돼도 계속 뜨지 말고 호버 시". 참고 화면처럼 📌를 색으로 채우지는 않는다). 버튼이 안 보일 때는 제목을 끝까지 보여 주고, 올렸을 때만 버튼 자리만큼 줄인다
- ⋯ 메뉴: 이름 바꾸기(줄 안에서 바로 고침, Enter 저장 · Esc 취소) · 삭제(빨간 글자, 한 번 누르면 "한 번 더 누르면 삭제돼요", 다시 눌러야 지운다). 파일은 편집기 저장 목록에서 바로 고치고(`renameEditorFile` · `deleteEditorFile`, state/recentEditorFiles.ts), 예시 대화는 이 브라우저에 덮어쓴다(`ddalkkak.chatOverrides`). 내 작업 목록도 같이 바뀐다
- 내 작업 목록에도 같은 ⋯ 메뉴(이름 바꾸기는 이름 칸에서 바로, 삭제는 한 번 더 눌러 확인). 오른쪽 열 [⋯][📌]는 마우스를 올렸을 때만, 고정한 파일은 이름 옆 📌로 표시. 대화는 고정 없이 ⋯만
- 새로 만들기 메뉴는 바깥을 누르거나 Esc를 누르면 닫힌다
- 새로 만들기 메뉴 모양(2026-11-20, 사용자 "더 추가될 수도 있는데 격자는 비효율적"): 2열 그림 격자 → **종류별 한 줄 목록**(Google Drive "새로 만들기" 방식). 묶음 = 문서(한글 · 워드 · PDF) / 표 · 발표(엑셀 · PPT) / 디자인 · 미디어(UI 디자인 · 이미지 · 영상), `EDITOR_GROUPS`(editor-shell/apps.ts). 줄 36px · 그림 아이콘 20px · 이름 14/500, 묶음 이름 12/600 회색, 묶음 사이 얇은 선. 화면을 넘으면 메뉴 안에서 스크롤. 편집기가 10개를 넘으면 맨 위에 검색 칸을 붙인다
- 접은 사이드바에서는 메뉴가 ＋ 버튼 오른쪽에 뜬다(스크롤 영역 밖으로 띄워야 잘리지 않아서 fixed 위치) → **최근**(편집기 파일과 대화를 한 목록에, 오늘 · 이번 주 · 이전으로 묶음, 10개) → "내 작업에서 모두 보기 ›". 최근 서식 묶음은 없어지고 최근에 합쳐진다(예시 대화는 시각이 없어 "이전").
- 접힌 줄(편집기 안): [로고] [＋] [홈] [내 작업]. 최근 파일 아이콘은 넣었다가 뺐다(같은 아이콘이 반복돼 구분이 안 되고, 떠오르는 사이드바와 겹침). 접힌 줄에 마우스를 올리면 떠오르던 동작은 넣었다가 뺐다(사용자 "호버 시 열리는 거 불편", 지나가기만 해도 튀어나옴). 펼치기는 맨 위 로고(≡) 누르기로만.
- 코드: `App.tsx` `SidebarDrawer`의 `planB` · `onNewEditor` 옵션과 `PlanBRecentList`.

## 에디터 상단 바 (두 시안 공통)
- 편집기 바꾸기 ▾(앱 격자)를 뺐다. 그 격자로 다른 편집기를 고르면 새 빈 파일이 열려서, 사이드바 ＋ 새로 만들기와 같은 일이었다.
- 다른 서비스: Google 문서(앱 아이콘 + 제목), Figma · Canva · 미리캔버스(제목만)는 에디터 안에 앱 바꾸기가 없다. Microsoft 365만 앱 격자가 있다(다른 앱 홈으로 가기).
- 결과: `[‹ 홈] [편집기 아이콘(툴팁 = 편집기 이름)] 제목 없음.hwpx [템플릿]`. "한글 편집기" 글자와 "/"는 없음. 파일이 없는 화면(UI 디자인 파일 목록)에는 편집기 이름을 보인다.
- 데스크톱(1200px 이상, 사이드바 줄에 홈이 보일 때)에서는 ‹(홈으로)도 숨긴다(홈 가는 길이 두 개였다). 태블릿 · 모바일은 ‹ 유지.
- 제목 옆 "✓ 저장됨" 상시 표시는 넣었다가 되돌렸다: 실제 딸깍 문서는 안쪽 오픈소스 에디터 머리에 "자동 저장" · "문서2 — 저장됨"이 이미 있어 두 번 보인다. 저장 중 · 실패일 때만 잠깐 보이는 원래 방식 그대로.
- 코드: App이 `onSwitchApp`을 넘기지 않고, `EditorHeader`는 `onSwitchApp`이 없으면 아이콘 + 제목만(편집기 바꾸기 격자 `AppSwitcher`는 지금 쓰이지 않음).
