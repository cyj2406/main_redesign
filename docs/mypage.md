# 마이페이지 기획 (2026-11-19 다시 정리)

코드: `src/app/components/mypage/MyPage.tsx` · 상태 `state/profile.ts`(이름·사진·AI 맞춤) · `state/account.ts`(로그인 방법·기기).

## 1. 다른 서비스

| 서비스 | 계정 화면에 있는 것 |
|---|---|
| Notion "내 계정" | 사진 · 표시 이름 · 이메일 · 비밀번호/2단계/패스키 · **모든 기기에서 로그아웃** · 계정 삭제 |
| Canva "계정·보안" | 이름·이메일 · **연결된 로그인 계정(Google 등)** · 모든 기기에서 로그아웃 · 계정 삭제(디자인·업로드도 함께 삭제, 구독 먼저 해지) |
| Claude 프로필 | **AI가 부를 이름 · 하는 일 · AI가 모든 대화에서 참고할 내 선호** |

출처: [Notion 계정 설정](https://www.notion.com/ko/help/account-settings) · [Canva 계정 설정](https://www.canva.com/help/account-settings/) · [Canva 계정 삭제](https://www.canva.com/help/delete-account/) · [Claude 개인화](https://support.claude.com/en/articles/10185728-understanding-claude-s-personalization-features)

## 2. 결정 — 지금 서비스에 있는 것만 (2026-11-19 사용자 정리)
다른 서비스의 "AI 맞춤 · 로그인 연결 관리 · 로그인된 기기" 같은 항목은 **딸깍에 아직 없는 기능**이라 새로 만들어야 한다. 그래서 마이페이지에는 이미 있는 데이터로 보여 줄 수 있는 것만 둔다.

1. **프로필** — 사진(변경·삭제) · 이름(수정, 공유·코멘트에 보이는 이름) · 이메일 · **로그인 방법**(Google 또는 카카오로 로그인했는지 표시만, 연결·해제 버튼 없음).
2. **내 이용 현황** — 요금제·크레딧(→ 요금제 및 크레딧) · AI 모델(→ 설정 › AI 모델). 요약과 바로 가기만, 관리는 각 화면. 내 작업은 사이드바에 이미 있어 뺐다(2026-11-19).
3. **계정** — 계정 삭제 요청(고객센터 안내, 구독 먼저 해지).

## 3. 뺀 것과 이유
| 뺀 것 | 이유 |
|---|---|
| 딸깍 AI 맞춤(부를 이름·하는 일·알려 둘 것) | 서비스에 없는 기능 |
| 로그인 연결·해제, 네이버 | 로그인은 Google·카카오만, 연결 관리는 서버 작업이 필요 |
| 로그인된 기기·다른 기기 로그아웃 | 서비스에 없는 기능 |
| 내 작업 내려받기 | 서버에서 파일을 묶어야 함 |
| 팀·초대·커서 색 | 각 작업물의 공유·코멘트에서 다룬다 |

나중에 서비스에 생기면 1장의 Notion·Canva·Claude 구성을 참고해 같은 카드 모양으로 추가한다.
