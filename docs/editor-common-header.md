## 2. 문제

1. **두 줄 헤더가 서로 겹친다.** 공통 상단 바 + 도구 안쪽 줄에 같은 기능이 반복: 공유(템플릿 편집기·레이아웃은 안쪽에도), 🔔(보정은 안쪽에도), 테마 ☀(포토·보정·영상 안쪽), 앱 아이콘(포토·벡터 안쪽 메뉴바 맨 앞).
2. **도구마다 버튼 세트·순서가 다르다.** 템플릿 편집기는 공유가 안쪽에, 다른 도구는 위에. "새로 만들기"는 템플릿 편집기에만, "레이어 분리"는 벡터에만 상단에.
3. **"코멘트"와 "0"이 따로**(코멘트 남기기 버튼과 개수 버튼이 나란히) — 역할이 헷갈린다.
4. **텍스트 버튼이 많아 길다** — "딸깍 AI · 템플릿 · 코멘트 · 0 · 공유 · 기록"이 앱 이름 옆에 이어져 파일 이름이 들어갈 자리가 없다(지금 대부분 파일 이름이 안 보임).
5. **좌우 패널을 다 열면 캔버스가 화면의 1/3** — 템플릿(왼쪽 400px) + AI(오른쪽 400px) + 서비스 레일.

## 3. 공통 헤더 구조 (제안)

```
┌───────────────────────────────────────────────────────────────────────────────────────────────┐
│ ‹  [아이콘] 딸깍 포토 ▾ / 가을 신메뉴 포스터            [도구 슬롯]     ✨ 💬3 🕘 │ ▷  [내보내기] [공유] 🔔 (나) │
└───────────────────────────────────────────────────────────────────────────────────────────────┘
   ① 정체성(왼쪽)                                           ② 도구 슬롯   ③ 패널 토글    ⑤ 결과물   ④ 알림·프로필(오른쪽 끝)
```

| 영역 | 내용 | 규칙 |
|---|---|---|
| ① 정체성 | ‹ 나가기(딸깍 홈) · 앱 아이콘 · **앱 이름 ▾**(다른 딸깍 편집기로 바로 이동, 아이콘 격자) · / · **파일 이름**(더블클릭 이름 바꾸기) · **저장 상태**(평소엔 없음, "저장 중…" / "저장 못 함"일 때만) | 모든 도구 같음. 새로 만들기: UI 디자인은 탭 줄 ＋, 문서 편집기(한글·워드·엑셀·PPT·PDF·영상·이미지)는 파일 탭 없이 템플릿 패널 "빈 문서"·사이드바 |
| ② 도구 슬롯 | 그 도구에만 있는 **핵심 행동 1~2개**(벡터 "레이어 분리" 등). 없으면 비움 | 많아지면 도구 안쪽 메뉴로. 상단은 2개까지 |
| ③ 패널 토글(아이콘) | ✨ 딸깍 AI · 💬 코멘트 목록(읽지 않음 배지) · 🕘 기록 — **오른쪽 패널을 여는 버튼은 오른쪽에** | 도구가 지원하는 것만 보인다. 순서 고정 |
| ④ 알림 | 🔔 — AI 작업 완료·멘션. **프로필 바로 옆 오른쪽 끝**(2026-11-19 이동: 파일 작업 버튼 사이에 끼어 있었다. 내 계정 소식이라 Google Docs·Notion·Canva·Figma처럼 프로필 옆) | 도구 안쪽의 🔔는 없앤다 |
| ⑤ 결과물 | ▷ 미리보기/프레젠테이션(지원 시) · **내보내기**(보조 버튼) · **공유**(채운 주요 버튼) · 맨 끝 내 프로필 | **공유가 없는 도구는 내보내기가 주요 버튼**이 된다(아래 4) |

- **템플릿은 상단에서 뺀다.** 왼쪽 패널을 여는 버튼이 오른쪽 위에 있으면 공간이 어긋난다. 도구 왼쪽 패널의 첫 탭으로(UI 디자인의 "파일·에셋·변수" 탭, Canva 왼쪽 사이드바 "디자인·요소·텍스트…"와 같은 방식).
- **저장·테마·🔔·앱 아이콘·공유는 도구 안쪽 줄에서 없앤다.** 저장은 자동 저장 + 상단 저장 상태로, 테마는 설정 › 화면 설정 한 곳.
- **도구 안쪽 메뉴바(파일·편집·…)는 남긴다**(포토·벡터·레이아웃처럼 전문 도구는 메뉴바를 기대한다). 다만 앱 아이콘을 빼고, 상단 헤더와 겹치는 항목(공유·저장·내보내기)은 메뉴에서만.
- 높이: 상단 48px, 도구 안쪽 줄 40px. 상단 바와 도구 줄 사이는 1px 선 하나.

### 프로필 → **오른쪽 끝에 하나만 둔다** (2026-11-19 수정 — 처음엔 뺐다가 사용자 피드백으로 복원)

- 함께 보는 사람은 프로필 옆에 늘어놓지 않는다. **공유 버튼에 인원 배지도 두지 않는다**(2026-11-19 피드백). 공유 팝오버의 "지금 함께 보는 중"(실시간 접속 표시)도 2026-11-19 뺐다(사용자 "실시간 표시는 없어도 될 듯"): 팝오버는 초대 · 참여자 · 링크 복사만.

## 6. 적용 순서(제안)

1. `EditorHeader`에 기능 조합을 넘기는 방식 추가(`capabilities: { ai, comments, history, present, export, share }`, `toolSlot`, `saveState`, 앱 전환 ▾).
2. 템플릿 편집기 5종(같은 화면이라 한 번에) — 안쪽 공유·저장·내보내기를 위로 올리고 템플릿을 왼쪽 탭으로.
3. 포토·벡터·레이아웃 — 안쪽 메뉴바의 앱 아이콘·테마 정리, 공유·내보내기 위로.
4. 보정·영상편집 — 내보내기를 주요 버튼으로, 안쪽 🔔·테마 제거.
5. 공통: 서비스 사이드바는 아이콘 레일로 붙임, 프로필은 오른쪽 끝 하나(서비스와 같은 메뉴, 크레딧 포함).

## 7. UI 디자인 적용 내용 (2026-11-19)

- `EditorHeader` props: `currentAppId` · `onSwitchApp` · `onNewFile` · `saveState` · `capabilities { present, export, share }` · `presentLabel` · `onExport` · `toolSlot` · `actions`(DockButtons) · `viewers`.
- 앱 이름 ▾ = **아이콘 격자(4×2)**(2026-11-19 변경, Google Workspace·Microsoft 365 앱 런처처럼). 홈 "편집기 바로 열기"와 같은 8개·같은 그림·같은 이름(`editor-shell/apps.ts`의 `EDITOR_APPS` 한 곳, 홈 줄도 이걸 쓴다). 지금 편집기는 브랜드 연한 바탕, 못 여는 도구는 흐리게 "준비 중"(`soon`, 2026-11-19 PDF 연결 뒤 지금은 없음). 예전 17개 글자 목록 + "새 파일"은 없앴다(새 파일은 탭 줄 ＋).
- 저장 상태(2026-11-19 다시 간소화): 평소(저장됨)엔 **아무것도 안 보인다**. 구름 아이콘은 뜻이 잘 안 읽혀(사용자 "있어야 하나") 없앴다. Figma·Canva처럼 자동 저장이 기본이라 표시하지 않고, "저장 중…"·"저장 못 함"일 때만 글자로 알린다. 안쪽 에디터가 저장 상태를 보여 주는 도구(한글·워드)는 헤더에 두지 않는다.
- UI 디자인 기능 조합: ▷ 프레젠테이션 · 공유(주요). 내보내기는 메인 메뉴에만(준비 중)이라 헤더에 버튼 없음. 도구 슬롯 없음.
- 크레딧: 프로필 메뉴의 크레딧 카드에서만 보여 준다(AI 입력창 아래 잔액·충전 줄은 2026-11-19에 뺌).
- 프로필: 헤더 오른쪽 끝 하나. **메뉴는 서비스 상단바와 같은 컴포넌트** `components/account/ProfileMenuButton`(2026-11-19, 크레딧 카드·튜토리얼·문의·커뮤니티·로그아웃까지 동일). 다른 화면으로 가는 항목(마이페이지·요금제 및 크레딧·튜토리얼)은 에디터를 닫고 가고, 설정·크레딧 내역은 에디터 위에 설정 모달. 공유 버튼 인원 배지 없음. 버전 기록은 🕘(아래 "9", 2026-11-19 구현). 홈 탭은 ✨만.

- **딸깍 AI는 글자 버튼(2026-11-19)**: 핵심 기능이라 아이콘(✨)만 두면 잘 안 보인다는 피드백. 패널 토글 중 AI만 "✨ 딸깍 AI" 글자 버튼(`DockTab.emphasized`)으로,
  닫혀 있어도 브랜드 연한 바탕·파란 글자로 보이고 열리면 파란 테두리. 코멘트 목록은 아이콘 그대로. Canva "Canva AI"·Notion "Notion AI"처럼 이름을 함께 둔 방식.

## 12. 딸깍 AI 패널 머리 정리 (2026-11-19)
- 사용자 "대화 목록을 위에 가서 봐야 할까, 사이드바도 있는데 / 프로젝트는 ＋에". 다른 서비스 패널(Copilot in Word·Gemini in Docs)은 파일마다 대화가 하나로 이어지고 머리 버튼이 거의 없다.

- **새 대화는 대화가 있을 때만** 보인다(흐린 아이콘이 고장 난 것처럼 보였다).

  - **파일 올리기**: "이번 요청에만 붙여요 · 이미지, PDF, .fig"
  - **프로젝트 파일 올리기**: "이 파일에서 AI가 매번 참고해요". 고르면 바로 파일 선택 창 → 올린 뒤 프로젝트 자료 패널이 열려 목록과 지침을 보여 준다.
  - 등록된 자료가 있을 때만: "프로젝트 자료 보기 (개수)" · "프로젝트 파일에서 고르기 ›"(이번 메시지에 첨부). "선택 영역을 이미지로 첨부"는 쓸 수 있는 편집기에서만.

## 13. 상단 바 반응형 (2026-11-19)
사용자 "작아질수록 좁으면 아이콘만 있는 버튼으로". 상단 바 너비로 세 단계(`EditorHeader`의 `HeaderLevelContext` · `useHeaderLevel` · `HeaderLabel`):

|---|---|---|
| 1180px 이상 | 0 | 이름 다 보임: [템플릿] [딸깍 AI] [버전 기록] [코멘트] [▷ 프레젠테이션 ▾] [내보내기] [공유] |
