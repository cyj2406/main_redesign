# 시작 튜토리얼 (2026-11-20, 지금 홈과 홈 B안)

목표: 에디터가 복잡해 보여도 **템플릿 하나 누르기, 딸깍 AI 한 번 시키기** 두 번이면 된다는 걸 30초 안에 직접 해 보게 한다.
참고: Canva(바로 열어 직접 해 보기), Figma(연습 파일), ChatGPT·Gamma(추천 문장 한 번 누르기), Slack·Figma(처음 쓸 때 점 힌트).

## 원칙
- 반짝임 테두리: 누를 곳 둘레 2px 파랑 + 3px 띄움, 모서리는 대상의 둥글기를 따른다. 템플릿 카드는 카드 전체(글자까지)가 아니라 미리보기 그림 칸만 감싼다(사용자 "강조 보더가 애매하다").
- 말풍선 글자 위계: 제목 18 굵게(#0f172a), 설명 14 보통 굵기 회색(#64748b).
- 2단계는 "골라야 한다"가 아니라 "필요하면 바로 쓸 수 있다"로. 3단계는 추천 문장 강조 대신 입력창에 실제로 적어 보내는 흐름(2026-11-20 사용자).
- 3단계까지만. 제목 한 줄, 설명 한 줄.
- 읽게 말고 누르게: 2, 3단계는 밝힌 자리를 직접 누르면 넘어간다(밝힌 자리는 눌리고 어두운 바깥만 막힌다). 누르기 싫은 사람을 위해 [다음], [끝내기]도 둔다.
- 시작 전에 "30초"를 보여 주고 고르게 한다([혼자 둘러볼게요] [30초 따라 하기]).
- 건너뛰어도 손해 없게: 편집기 상단 버튼의 파란 점 힌트.

## 흐름
| 단계 | 화면 | 밝히는 곳 | 문구 | 넘어가는 방법 |
|---|---|---|---|---|
| 1/3 | 홈 | 지금 홈: 편집기 바로 열기 줄, B안: 새로 만들기 줄(한글 반짝임) | 만들 문서를 골라 시작해요 / 한글, 엑셀, PPT까지 쓰던 편집기를 그대로 써요. 한글로 30초만 따라 해 볼까요? | [30초 따라 하기] 또는 한글 누르기 → 한글 편집기. [혼자 둘러볼게요] = 끝. 다른 편집기를 누르면 끝 |
| 2/3 | 한글 편집기 | 왼쪽 템플릿 패널(첫 템플릿 반짝임) | 필요한 양식은 여기서 바로 써요 / 공문, 신청서처럼 정해진 양식을 누르면 문서에 바로 들어가요. 하나 눌러 볼까요? | 템플릿이 문서에 들어가면. 미리보기 창이 떠 있는 동안은 말풍선을 숨기고, 창 안에서 [이 서식으로 시작]을 반짝이며 회색 설명 자리에 "2/3 이 서식으로 시작을 눌러 양식만 넣어 봐요. 내용은 다음 단계에서 딸깍 AI가 채워 줘요."를 띄운다(`TemplatePreview` `guide`). [AI로 내용 채우기]를 눌러도 빈칸 카드는 펼치지 않고 3단계로 이어진다. [다음] |
| 3/3 | 한글 편집기 | 딸깍 AI 입력창([보내기] 반짝임) | 말로만 해도 채워 줘요 / 딸깍 AI에게 하고 싶은 걸 적으면 문서를 대신 써 줘요. 보내기를 눌러 보세요. | 입력창에 요청을 대신 타이핑해 둔다("○○ 내용을 채워 줘", 템플릿이 없으면 "행사 개최 알림 공문 써 줘"). [보내기]나 Enter를 누르면 말풍선을 걷고 AI가 쓰는 걸 보여 준다. 결과가 들어가면 끝, 0.9초 뒤 공유 마무리 말풍선(아래). [끝내기] |

코멘트, 공유는 단계로 두지 않는다. 공유는 받는 사람이 있어야 해 볼 수 있어서 "따라 하기"가 안 되고, 4단계가 되면 30초 약속이 흐려진다.

**공유 마무리 말풍선(2026-11-27, 토스트를 바꿈)**: AI 결과가 들어가거나 3단계 [끝내기]를 누르면 0.9초 뒤 상단 [공유] 아래에 띄운다([끝내기]는 이름 때문에 다 했다고 여기고 누르는 사람이 많아서 같이 띄운다). 단계 수에 안 센다(점 3개를 다 채우고 "다 했어요").
- 제목 "함께 고치려면 공유해요", 설명 "링크를 보내면 받는 사람이 문서에 바로 코멘트를 남길 수 있어요. 파일을 주고받지 않아도 돼요." [확인]
- 화면을 어둡게 하거나 막지 않는다(방금 AI가 쓴 문서가 보이게). [공유] 둘레에 파란 테두리만.
- [확인], [공유] 누르기(공유 창은 그대로 열림), Esc, 편집기 나가기로 닫힌다. 머리줄 건너뛰기, Esc, 2단계에서 끝낸 사람에게는 안 띄운다.
- 토스트는 몇 초 뒤 사라지고 "오른쪽 위"라는 말로만 자리를 알려 줘서, 버튼을 직접 가리키는 말풍선으로 바꿨다.
- 이벤트: starter_share_tip_view, starter_share_tip_close(via: ok · share · esc).

## 건너뛴 사람용 힌트
- 편집기 상단 [템플릿] 오른쪽 위 파란 점(번지는 애니메이션). 마우스를 올리면 "정해진 양식이 필요하면 여기서 골라요". 한 번 누르면 사라진다.
- [딸깍 AI]도 같은 점("어려우면 딸깍 AI에게 말로만 하세요"). 패널이 열려 있을 때는 점을 보이지 않는다(이미 보이니까).
- 튜토리얼을 끝까지 하면 둘 다 본 것으로 친다. 튜토리얼 중에는 숨긴다.

## 시작과 다시 보기
- 홈 첫 방문 1회 자동(지금 홈, B안 같은 기록)(`localStorage["ddalkkak.onboarding.starterSeen"]`), 홈이 그려지고 600ms 뒤.
- 프로필 메뉴 "튜토리얼 다시 보기" → 홈으로 가서 1단계부터. 예전 홈 온보딩(검색창 → 편집기 줄, `HomeOnboarding.tsx`)은 더 띄우지 않는다(파일은 남김).
- 편집기를 닫으면 튜토리얼도 끝. ESC = 건너뛰기(2, 3단계).
- 기록: `track()` starter_start, starter_step_view, starter_follow, starter_skip, starter_complete, starter_share_tip_view, starter_share_tip_close.
